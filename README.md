# sheroes-nx

A native Nintendo Switch homebrew (and PC) port of Sonic Heroes (original Xbox, USA), made by static recompilation
of the Xbox executable with xboxrecomp.

## Status

Early bring-up. Nothing to download yet.

## You need your own game

The disc image is not included and never will be. You extract your own copy of the Xbox disc.
